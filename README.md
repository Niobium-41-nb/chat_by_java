# Java QQ 聊天系统

## 项目简介

这是一个基于 Java Socket 编程实现的简易 QQ 聊天系统，支持多客户端同时在线聊天、私聊、文件传输等功能。系统包含服务器端和客户端，采用图形化界面，模拟了基本的即时通讯功能。

## 功能特性

### 已实现功能

- ✅ **多客户端支持**：支持多个用户同时在线聊天
- ✅ **并行通信**：客户端可以独立发送和接收消息，不受其他客户端影响
- ✅ **私聊功能**：使用 `$用户名` 格式进行私密聊天
- ✅ **图形化界面**：仿 QQ 风格的聊天界面
- ✅ **用户管理**：显示在线用户列表，支持双击快速选择私聊对象
- ✅ **文件传输**：支持端到端的文件传输（Base64 编码）
- ✅ **系统消息**：用户加入/离开的实时通知
- ✅ **连接管理**：稳定的连接建立和断开处理

### 界面功能

- **登录界面**：服务器地址和端口配置
- **好友管理**：实时显示在线用户列表
- **聊天界面**：消息显示区域、输入框、功能按钮
- **文件传输**：文件选择、发送、接收确认

## 运行说明

### 环境要求

- Java 8 或更高版本
- Windows/Linux/macOS 系统

### 编译运行

1. **编译所有 Java 文件**：
   ```bash
   javac *.java
   ```

2. **启动服务器**：
   ```bash
   java MultiTalkServer
   ```
   或者使用单线程版本：
   ```bash
   java SingleTalkServer
   ```

3. **启动客户端**：
   ```bash
   java SingleTalkClient
   ```

### 使用步骤

1. 首先启动服务器程序
2. 启动一个或多个客户端程序
3. 在客户端界面输入服务器地址和端口（默认：127.0.0.1:8898）
4. 点击"连接"按钮建立连接
5. 开始聊天：
   - 普通消息：直接输入文本发送
   - 私聊消息：使用 `$用户名 + 消息内容` 格式
   - 文件传输：选择在线用户后点击"发送文件"按钮

## 技术实现

### 服务器端技术

- **多线程处理**：每个客户端连接使用独立线程
- **线程安全**：使用 `synchronized` 和 `Collections.synchronizedMap` 保证线程安全
- **消息路由**：根据消息内容自动路由到广播或私聊
- **连接管理**：客户端连接状态的维护和清理

### 客户端技术

- **Swing GUI**：图形用户界面
- **事件驱动**：按钮点击、输入响应等事件处理
- **网络通信**：Socket 连接和数据传输
- **文件处理**：Base64 编码的文件传输
- **多线程**：独立的消息接收线程

### 通信协议

- **普通消息**：直接文本传输
- **私聊消息**：`$用户名 + 消息内容`
- **系统消息**：`WELCOME:用户名`、`ONLINE_USERS:用户列表`
- **文件传输**：`FILE:目标用户:文件名:Base64数据`
- **控制命令**：`Bye.`（断开连接）、`GET_USERS`（获取用户列表）

## 注意事项

1. **文件大小限制**：单文件传输限制为 1MB
2. **编码格式**：文件传输使用 Base64 编码
3. **网络要求**：确保服务器端口 8898 未被占用
4. **用户命名**：系统自动分配用户名（user0, user1...）
5. **私聊语法**：私聊时使用 `$用户名 消息内容` 格式
