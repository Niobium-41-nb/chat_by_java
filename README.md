# 增强版聊天系统

一个基于Java的多客户端聊天系统，支持图形用户界面、并行通信、文件传输和群聊功能。

## 功能特性

### 已实现功能

1. **多客户端通信** (20分)
   - 支持多个客户端同时连接
   - 通过服务端中转实现客户端间通信
   - 实时消息转发

2. **并行通信模式** (20分)
   - 端到端的并行通信
   - 消息发送不受另一端影响
   - 异步消息处理

3. **图形用户界面** (50分)
   - **登录界面**：用户名验证，登录失败提示
   - **好友管理界面**：显示好友列表和在线状态
   - **聊天界面**：类似QQ的聊天界面设计
     - 聊天消息显示区域
     - 消息输入框
     - 好友列表和在线用户列表
     - 功能按钮面板

### 可选功能（选做）

4. **文件传输** (30分)
   - 客户端间文件传输
   - 传输进度显示
   - 文件传输会话管理

5. **群聊天** (30分)
   - 多人群组聊天
   - 群组管理（创建、加入、退出）
   - 群消息广播

## 系统架构

```
增强版聊天系统
├── EnhancedMultiTalkServer.java    # 主聊天服务器
├── EnhancedChatClient.java         # 图形界面客户端
├── FileTransferServer.java         # 文件传输服务器
├── GroupChatManager.java           # 群聊管理器
└── 启动增强版聊天系统.bat          # 系统启动脚本
```

## 运行说明

### 环境要求
- Java 8 或更高版本
- Windows 操作系统（支持批处理脚本）

### 快速启动

1. **方法一：使用启动脚本（推荐）**
   ```bash
   # 双击运行
   启动增强版聊天系统.bat
   ```

2. **方法二：手动编译运行**
   ```bash
   # 编译所有Java文件
   javac *.java
   
   # 启动聊天服务器
   java EnhancedMultiTalkServer
   
   # 启动客户端（新命令行窗口）
   java EnhancedChatClient
   ```

### 使用步骤

1. **启动服务器**
   - 运行 `EnhancedMultiTalkServer`
   - 服务器将在端口 8898 监听连接

2. **启动客户端**
   - 运行 `EnhancedChatClient`
   - 在登录界面输入用户名
   - 服务器地址：127.0.0.1，端口：8898

3. **开始聊天**
   - 登录成功后进入主界面
   - 查看好友列表和在线用户
   - 发送消息：
     - 普通消息：直接输入发送
     - 私聊消息：@用户名 消息内容
     - 群发消息：使用群发功能按钮

## 功能详细说明

### 聊天功能
- **广播消息**：发送给所有在线用户
- **私聊消息**：使用 `@用户名 消息内容` 格式
- **系统消息**：用户上线/下线通知
- **实时更新**：好友列表和在线用户实时更新

### 界面功能
- **登录界面**：简洁的用户认证
- **主界面**：三栏布局（联系人、聊天区、功能按钮）
- **联系人列表**：显示好友和在线用户，支持双击快速私聊
- **聊天区域**：实时显示聊天记录，自动滚动
- **功能按钮**：
  - 刷新好友列表
  - 刷新在线用户
  - 群发消息
  - 文件传输
  - 清空聊天
  - 退出系统

### 文件传输
- 独立的文件传输服务器（端口 8899）
- 支持文件上传和下载
- 传输进度监控
- 会话管理

### 群聊功能
- 预定义群组：技术交流、休闲聊天、学习小组、游戏天地
- 用户可加入/退出群组
- 群消息广播
- 群组成员管理

## 技术特点

1. **多线程处理**：使用线程池处理并发连接
2. **并行通信**：消息接收和发送独立处理
3. **图形界面**：Swing框架，事件驱动编程
4. **网络通信**：Socket编程，TCP协议
5. **数据管理**：并发集合保证线程安全
