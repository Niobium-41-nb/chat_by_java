# Java QQ 聊天系统

基于Java Socket编程实现的即时通讯系统，具有图形用户界面，支持多客户端通信。

## 功能特性

### 已实现功能

1. **基础通信** (10分)
   - 单客户端通信 (SingleTalkServer/SingleTalkClient)
   - 多客户端通信 (MultiTalkServer)

2. **多客户端单独通信** (20分)
   - 支持多个客户端同时连接
   - 客户端间通过服务器中转进行私聊
   - 支持群聊功能

3. **并行通信模式** (20分)
   - 端到端的并行通信
   - 消息发送不受另一端影响
   - 实时消息接收和显示

4. **图形用户界面** (50分)
   - 登录界面和失败提示
   - 好友管理界面
   - 聊天界面（参照QQ设计）
   - 支持私聊和群聊

### 选做功能

5. **端到端文件传输** (30分，选做)
   - 暂未实现

6. **群聊天功能** (30分，选做)
   - 已实现基础群聊功能

## 系统架构

### 服务器端
- `EnhancedMultiTalkServer.java` - 增强版多线程服务器
- `MultiTalkServer.java` - 基础多线程服务器
- `SingleTalkServer.java` - 单线程服务器

### 客户端
- `QQLoginFrame.java` - 登录界面
- `QQMainFrame.java` - 主聊天界面
- `QQIntegratedClient.java` - 集成网络通信的客户端
- `EnhancedMultiTalkClient.java` - 命令行增强客户端
- `SingleTalkClient.java` - 基础命令行客户端

## 使用方法

### 启动系统

1. **启动服务器**：
   ```bash
   java EnhancedMultiTalkServer
   ```

2. **启动客户端**：
   ```bash
   java QQLoginFrame
   ```

### 使用说明

1. **登录**：
   - 运行 `QQLoginFrame` 启动登录界面
   - 输入用户名和密码
   - 登录成功后进入主界面

2. **聊天功能**：
   - 在好友列表中选择要聊天的对象
   - 在消息输入框中输入内容
   - 按回车或点击发送按钮发送消息

3. **命令说明**：
   - `@用户名 消息内容` - 私聊指定用户
   - `all 消息内容` - 发送群聊消息
   - `list` - 查看在线用户
   - `bye` - 退出程序

## 技术特点

1. **多线程处理**：服务器为每个客户端连接创建独立线程
2. **并发控制**：使用 `ConcurrentHashMap` 管理客户端连接
3. **图形界面**：使用 Swing 实现友好的用户界面
4. **网络通信**：基于 TCP Socket 实现可靠的数据传输
5. **事件驱动**：使用事件监听器处理用户交互

## 文件说明

- `EnhancedMultiTalkServer.java` - 主服务器，支持认证、私聊、群聊
- `QQLoginFrame.java` - 登录界面，包含认证逻辑
- `QQMainFrame.java` - 主聊天界面，支持好友列表和聊天窗口
- `QQIntegratedClient.java` - 集成图形界面和网络通信的完整客户端
- 其他文件为原始代码和基础实现

## 编译运行

所有Java文件已编译完成，可以直接运行：

```bash
# 启动服务器
java EnhancedMultiTalkServer

# 启动图形客户端（推荐）
java QQLoginFrame

# 或启动命令行客户端
java EnhancedMultiTalkClient
```
